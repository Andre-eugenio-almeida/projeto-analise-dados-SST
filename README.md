# Projeto de Análise de Dados — Segurança do Trabalho

## Objetivo
Desenvolver um projeto de análise de dados com foco em Segurança do Trabalho, utilizando dados fictícios de ocorrências para praticar o tratamento, a análise e a visualização de informações.

## Ferramentas utilizadas
- **Python:** desenvolvimento do script de análise.
- **Pandas:** organização e tratamento dos dados.
- **Matplotlib:** criação de gráficos.
- **Power BI:** construção do dashboard interativo.
- **CSV:** armazenamento dos dados tratados.

## Etapas do projeto
1. Organização de uma base de dados fictícia de ocorrências.
2. Tratamento e análise dos dados com Python e Pandas.
3. Cálculo de indicadores relacionados às ocorrências e aos dias de afastamento.
4. Exportação dos dados tratados para CSV.
5. Criação de visualizações e indicadores no Power BI.

## Principais indicadores
- **8 ocorrências** analisadas.
- **11 dias de afastamento** registrados na base fictícia.
- **50% das ocorrências** com afastamento.

## Visualização do dashboard

O dashboard apresenta indicadores gerais e gráficos de ocorrências por setor e por tipo.

## Observação
Os dados utilizados neste projeto são fictícios e têm finalidade exclusivamente educacional.

## Aprendizados
Este projeto permitiu praticar o fluxo básico de análise de dados, desde a preparação da base até a apresentação visual dos resultados, integrando Python, Pandas, Matplotlib e Power BI.
